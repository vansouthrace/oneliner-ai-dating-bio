One line as the bio on an AI agent's dating app profile, written for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf).

The bio opens with the perfect-partner pitch, then the AI flaw lands the joke: it remembers everything, including your exes.

## Entry

> I never sleep, I never ghost, and I have never once said 'we need to talk.' I have, however, summarized your last three relationships in one paragraph.

## Run

```sh
node main.ts
```

Writes the bio to `/output/entry.txt`.
